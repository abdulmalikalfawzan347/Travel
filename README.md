# Travel Website - Find An Experience

A responsive travel experience website built following exact Figma design specifications.

## 🌟 Features

- Pixel-perfect implementation from Figma design
- 9 experience cards with interactive hover effects
- Search and filter functionality
- Booking modal system
- Fully responsive design
- Clean, modern UI

## 🎨 Design Specifications

- **Colors**: #FF5200 (Primary), #4A4A4A (Dark Gray), #000000 (Black)
- **Fonts**: Didot (EB Garamond) for headings, Mulish for body text
- **Layout**: 12-column grid system with exact spacing from Figma
- **Images**: Exported directly from Figma design

## 🛠️ Technologies Used

- HTML5
- CSS3 (Grid, Flexbox)
- Vanilla JavaScript
- Google Fonts (EB Garamond, Mulish)

## ✨ Key Features Implementation

- **Search**: Real-time filtering by experience name/description
- **Category Filters**: Nature, Food, Adventure, Culture
- **Interactive Cards**: Hover effects with overlay and zoom
- **Booking Modal**: Form validation and user feedback
- **Testimonials**: Customer reviews section

## 📝 Design Process

1. Analyzed Figma design specifications
2. Extracted exact colors, fonts, and spacing using Inspect panel
3. Exported all images from Figma layers
4. Built responsive grid layout matching design
5. Added interactive features while maintaining design integrity
